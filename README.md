# PastelLife

An Android personal task and finance manager starter built with Kotlin and Jetpack Compose.

## Current status
This repository is the initial app foundation. It is not a finished production app yet.

Planned features include offline-first tasks, account balances, income/expenses, receivables/payables, reports, reminders, and optional cloud sync.

## Build
Open this repository in Android Studio or use the GitHub Actions workflow to build a debug APK. The build must be checked in Actions before treating an APK as verified.
